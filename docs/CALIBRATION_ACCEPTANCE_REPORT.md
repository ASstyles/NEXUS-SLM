# NEXUS-SLM Confidence Calibration Acceptance & Epistemic Uncertainty Report

## 1. Executive Summary & Epistemic Risk Definition

In automated decision systems, a model's predicted confidence must represent the true empirical probability of its correctness:
$$\mathbb{P}(\hat{Y} = Y \mid \hat{P} = p) = p, \quad \forall p \in [0, 1]$$

When a model is miscalibrated (specifically overconfident), downstream routing systems make silent errors, automating high-risk tickets without human review.

This report documents the multiclass calibration audit of the experimental `qwen25_05b_clean_v2_lora` candidate, establishes the mathematical limitations of sequence token probabilities, and formalizes production confidence invariants.

$$\text{ECE} = \sum_{m=1}^M \frac{|B_m|}{N} \left| \text{acc}(B_m) - \text{conf}(B_m) \right|$$

### 2.2 Forensic Analysis: The Generative Token Logprob Fallacy
1. **Token Likelihood vs Class Posterior:**
   - In autoregressive causal generation, the model predicts the token string `{"category": "fraud_report", ...}`.
   - The sequence confidence is computed via the geometric mean of token probabilities for the predicted category name.
   - **Crucial Mathematical Defect:** This reflects the model's confidence in emitting English syntactic tokens, NOT the true posterior probability distribution over all 14 mutually exclusive support categories:
   $$\prod_{i=1}^k P(t_i \mid t_{<i}) \neq P(C = \text{fraud\_report} \mid \text{ticket})$$
2. **Pathological Bin Clustering:**
   - Due to teacher-forcing during instruction tuning, all 746 test predictions clustered into the highest bin ($[0.90, 1.00]$).
   - The model expressed $\ge 95\%$ confidence even on tickets it completely misclassified (e.g. collapsing `general_query` into `fraud_report`).
3. **Failure of Global Temperature Scaling:**
   - Applying global temperature scaling ($T=1.15$) adjusted average confidence from 97.68% to 96.29%, failing to separate correct from incorrect predictions.

Because neural confidence does not currently satisfy calibration standards:

1. **Heuristic Fallback Designation:**
   - All responses generated by the Production Heuristic Fallback V2 engine strictly set `confidence: null` and `calibrated_confidence: null`.
   - The system metadata explicitly records `confidence_calibration: "uncalibrated_heuristic"`.
2. **Prohibition of Straight-Through Confidence Routing:**
   - Autonomous routing without human review based purely on `raw_confidence > \tau` is **STRICTLY PROHIBITED**.
   - Automated routing is permitted ONLY via the deterministic 7-tier rule hierarchy in `HumanEscalationPolicy`, which verifies category safety, script modality, financial thresholds, and inquiry ambiguity.
3. **Low-Confidence Safeguard Invariant:**
   - If an experimental neural model produces `confidence < 0.70`, Rule 5 in `HumanEscalationPolicy` deterministically forces `requires_human = True` under reason `low_confidence_uncertainty`.
